# Замер r5 после D-066, D-067 и D-068

Ядро — рабочее дерево с D-066, D-067 и D-068 (итоговые прогоны после появления D-068 в коде). По 1000 партий на бота, зёрна `s0…s999`. Данные — `sim/out/2026-11-04-r5-*.json` и `.md`, метрики D-066/D-067 считает `npx tsx sim/report5.ts <файл.json>`.

**Итог:** на текущем `balance.ts` в коридоре 35–65 % только «Чистые руки» (53.7 %). «1984» 98.9, «Тень» 86.2, «Кардинал» 77.1, «Монополия» 73.3. Причина — D-066 (выработка на человека удвоилась), а не дилеммы. Пакет C3 из шести констант (§4) возвращает все пять путей в 54–60 %.

## Изменения в `sim/`
- **Команды по D-066** (`kit.ts`, `runCasesD066`): на дела идут одиночки, пока дел не меньше, чем свободных агентов; ведущий расследования — самый слабый агент, который один даёт шанс ≥ 0.5; подкрепление: на теракт до 2 лучших бойцов, на расследование d3 +1, d4–5 +2, только из «лишних» людей; затем лишние агенты подкрепляют идущие операции (`reinforceOp`, пока прогресс < 50 %); `planHire` нанимает, когда свободных агентов 0. Старое поведение — флаг `#legacy` (на s0–s49 совпадает со старыми ботами побитово).
- **Выбор в дилеммах и линейке** — в имени бота: `#dl=default|honest|dirty|random`, `#line=decline|honest|dirty|random`, `#el=silent|announce|leak`, `#sig=…`, `#only=<дилеммы>`. Код: `dlConfig`, `handleDilemma`, `lineDecision`. Политика по умолчанию у каждой стратегии — лучшая для её пути по матрице 3 × 3; у «Монополии» и «Кардинала» это честные варианты дилемм.
- **Новые метрики в `game.ts`:** размер команды, гибель на терактах, окна и причины сгорания дилемм, `history`, план по годам, изъятие остатка в квартале выплаты линейки, исходы линейки, выборы, дела с тегами.

## 2. Причина
- **D-066 удвоил выработку на человека.** 8 агентов раньше вели 4 дела, теперь 8. Поток дел — 6–9 в месяц, штат из 6–8 человек забирает почти всё. У малых штатов «грязных» путей исчезла прежняя цена.
- У «1984» `plan_ratio` 1.8–2.3, бюджет на M48 824 → 1852, Репрессии 7 к M38 (было M44). «Тень» выполняет план в 72–77 % кварталов (было 35.7 %).
- Разложение. 1984@8: r4 48.8 → старые боты на новом ядре 59.3 → только D-066 с новыми ботами 96.8. «Тень»: 40.9 → 59.4 → 79.8.
- **Линейка — добавка путям, которым не хватает денег:** cardinal@12 52.9 → 66.4, 1984@10 74.2 → 83.0 (без линейки → с ней).
- **Грязные варианты дилемм вредят грязным путям:** «Монополия» 69.9 → 54.0, cardinal@12 70.4 → 55.8 — их «Под следствием» и так 37–53, грязь переводит его за порог заморозки дохода 50.

## 3. Проверки §10.5

**D-066**
1. План честного по годам — в коридоре: 1.37 / 1.27 / 1.33 / 1.31 / 1.26. `PLAN_BASE_BY_YEAR` не трогать. Бюджет > 0 на M48 у 99–100 % доживших.
2. «Чистые руки» 53.7 % — в коридоре.
3. «Тень» не просела, а выросла: 40.9 → 86 %.
4. «Кардинал» +18–25 п.п. вместо +1–3: сам D-066 дал +0.7, остальное — честные дилеммы (+9) и линейка (+7…+13).
5. Гибель на терактах: 0.17–0.30 агента за партию, 0.09–0.15 на провал. Команды 1/2/3: honest 4/10/86 %, 1984@8 19/29/52 %, shadow 36/27/37 %.
6. Случайный бот до M11 погибает в 0.6 % партий (цель ≤ 5.5 %).

**D-067**
1. **Окна дилемм 0.27 в месяц — вне коридора 0.5–1.** «Признание под давлением» сгорает 5.4–5.9 раз за партию (в фазе не выполняется `p_shown < 0.6`), открывается 0.4–0.8 раза, а каждое сгорание ставит откат 30 дней; у расследований всего три дилеммы с повтором 180 дней. Свип `DILEMMA_OP_CHANCE` 0.18/0.25/0.35 → 0.28/0.30/0.32; повтор 90 + шанс 0.2 → 0.35. Константами не лечится.
2. «Чистые руки» и «Тихий сигнал»: без сигналов 51.8, «Отложить» 52.5, «По правилам» 53.7 — проседания нет, `attackRep` −8 остаётся. Сигналов 3.6–3.8 за партию, пропущенных терактов 0.63–0.68.
3. **Грязные варианты выгоднее в среднем, но разброс не растёт.** На честной базе (honest@12) грязь — бесплатная прибавка: очков плана 351.6 ± 51.7 против 313.9 ± 61.6, бюджет на M48 1839 против 1250, банкротств 2.5 % против 5.2 %, катастроф 0. Ужесточение `judgeChance` 0.6, `exposeK` 0.08 почти ничего не меняет. На грязной базе (dirty@14) разброс и катастрофы растут (5.0 против 3.2 %).
4. **Линейка в порядке:** стартов 1.8 за партию у честных, 0.7–1.1 у остальных; успех на старт 57–78 % (почти всегда с напарником); потеряно агентов на старт 0.06–0.12 (цель ≤ 0.25); изъятие остатка забирает 0.3–12 % выплаты.
5. **Выборы и «Кардинал»:** «Объявить» лучше «Молчать» на 1.3–2.3 п.п. (60.0 против 58.7 у @10). Побед после M47 у @12: 40.4 против 37.7 %. «Слить» хуже «Молчать» (37.2 %).

Прочее: катастрофа от следствия у грязных ботов — 0.8–6.4 % при цели 10–25 %.

## 5. Формулы (для gdd-designer, затем core-architect)
1. **Окна дилемм.** Проверять `p_shown < maxChance` уже при назначении; сгоревшая дилемма снимает откат (`nextDay = day`). Оценка без замера — 0.38–0.45 окна в месяц. Для 0.5–1 нужен больший каталог либо цель v1 «0.3–0.4 операционных окна».
2. **Накопительный риск грязи.** Например, ежемесячный `roll(k · hidden_sins)` с ударом по доле бюджета или влиянию — иначе на честной базе грязь бесплатна.
3. **Цена честности в «Тихом сигнале».** −8 репутации при её уровне ~95 исход не меняет; бить лучше влиянием или долей бюджета.
4. **Цены пути «1984» не работают:** 10 скандалов за партию, а репутация 92 (её поднимает план +3 за квартал); бунтов 0; удержание не срывается. Если выбрать формулу вместо констант, пакет C3 по «1984» нужно перемерить.

## 6. Воспроизведение
```
# до (текущий balance.ts); список ботов — meta.bots в sim/out/2026-11-04-r5-final-base.json
npx tsx sim/run.ts --n 1000 --label r5-final-base --bots <список>
# после (пакет C3); $LEAK — ACT_LEAK с repPerStrength -3, строка в meta.set файла r5-final-c3.json
npx tsx sim/run.ts --n 1000 --label r5-final-c3 --bots <тот же список> --set "ACT_LEAK=$LEAK" --set ILLEGAL_TARGET_EXPOSURE=15 --set SHADOW_HOLD_DAYS=270 --set NET_PROGRESS_PER_AGENT=0.18 --set VICTORY_1984_HOLD_DAYS=540 --set 'REPR_COST_BY_LEVEL=[180,360,540,720,900,1080,1260]'
# метрики D-066/D-067
npx tsx sim/report5.ts sim/out/2026-11-04-r5-final-base.json
```
Разложения: `r5-asis`, `r5-d066only`, `r5-decomp`, `r5-matrix`, `r5-dlvalue`. Свипы: `zdl-*`, `t-nofc-*`, `x1984-*`, `y*`, `w-*`, `v-*`, `u-*`, `s-*`, `q-*`. Прогоны до D-068 (`r5-pre`, `r5-matrix`, `r5-decomp`, `r5-d066only`, `r5-dlvalue`) годятся только для сравнений внутри одного прогона.
