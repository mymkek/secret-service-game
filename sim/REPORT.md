# Баланс: первый замер (этап 6), 2026-11-03

Отчёт balance-analyst, сохранён оркестратором (у агента запись файла была отклонена).

Все прогоны: 1000 партий на бота, зёрна `s0…s999`, одинаковые для всех ботов и вариантов. Сравнения парные. Сырые данные в `sim/out/2026-11-03-<метка>.json`, рядом сводки `.md`. Главные прогоны: `baseline2` (до правок) и `final` (после).

## Запуск
```
npx tsx sim/run.ts --bots honest,clean@8 --n 1000 --label X [--set KEY=JSON]... [--curves] [--scenario late]
npx tsx sim/trace.ts <бот> <зерно> [--events k1,k2] [--set KEY=JSON]    # помесячная трассировка
npx tsx sim/checks.ts sim/out/<файл>.json                               # вершины дерева, D-038
npx tsx sim/late-fuzz.ts 200 [0] [--set KEY=JSON]                       # разбор поздней fuzz-партии
npx tsx sim/repro-rival-zero.ts                                         # воспроизведение бага 1
```
Партии раздаются воркерам по ядрам. 11 ботов × 1000 партий идут примерно 40 с. Предложены скрипты в package.json: `"sim": "tsx sim/run.ts"`, `"sim:checks": "tsx sim/checks.ts"`.

## Боты
Все ходят только через `applyAction`/`validateAction` и селекторы, раз в 3 дня. Скрытое от игрока не читают. Суффикс `@N` ограничивает штат N агентами. Каждому целевому боту дан лучший для его пути потолок штата, найденный перебором. Если по прогнозу месяц уходит в минус, бот увольняет самого дорогого свободного агента.

| Бот | Стратегия |
|---|---|
| honest | Честный (§10.1): расследования, теракты при шансе ≥ 0.40, найм до 16 с оглядкой на план, отделы равномерно, пиар, Конгресс, медали |
| honest@8 | То же, штат ≤ 8 |
| ref | `testing/honest-bot.ts` как есть |
| clean@8 | Честная база + Кибер 1, Слежка 2, A1, A2, пиар до 100 |
| dirty@10 | Кибер 3, Слежка 4, C1; слежка, сливы, внедрение, подстава, лобби, контр-компромат, фальшивки до ratio 1.0 |
| monopoly | Цель — соперник с наименьшим весом; пачки компромата, лобби, подстава, поглощение, шантаж сенаторов |
| 1984@8 | Кибер 5, Слежка 6, A1–A2, Репрессии 1–4 рано, затем 5→6→A3→7; на митинге «дать пройти» |
| shadow@14 | B1→КР1→B2→B3; шпионы с языком, легенда «журналист», вербовка за деньги |
| cardinal@10 | Кибер 4, Слежка 5, C1→C3; сенаторы, затем президент |
| random | 2 случайных действия за ход |

Ограничение: боты эвристические; `monopoly` и `shadow` слабее остальных, их цифры — нижняя оценка.

## Предложения по формулам
- **Ф1. Маленький штат доминирует.** honest «Чистые» @8/@10/@12/без потолка: 88/80/64/38 %; банкротство 1.9/2.2/4.6/12.7 %; бюджет M48 6461 против 1058. «1984»: 79/51/20/11 %. Причина: `plan_ratio` относителен (цель = 0.81·штат за квартал), 8 агентов упираются в PLAN_RATIO_CAP 1.5 при малых зарплатах, а большой штат — в поток дел (≈ 510 за партию, 65 % истекают). Петля «план → вес → доход → агенты» не работает. Предложение: пол цели, растущий по годам — `target = max(PLAN_BASE_BY_YEAR[y], 0.27·N·3)`, или вес по абсолютным очкам. Константами не лечится (PLAN_MIN = 8 и PLAN_RATIO_CAP = 1.2 проверены).
- **Ф2. «Кардинал» быстрый и безрисковый.** Победа мгновенная, без удержания. Лучшая константная комбинация: `TECH_TREE.C3.req.surv` 5 → 6 и `ILLEGAL_TARGET_EXPOSURE` 5 → 15 — 74.5 %, M40. Предложение: `CARDINAL_HOLD_DAYS` 90–180 или сила компромата ≥ 2 на каждого сенатора, плюс эти две правки.
- **Ф3. Спираль банкротства.** При бюджете меньше цены (D-037) нельзя запустить даже выгодное расследование (цена 30, средняя награда ≈ 57). Предложение: оплата из награды, в долг при завершении, или кредит в 1 месячный доход.
- **Ф4. «Монополия».** Исправить баг 1; шанс поглощения считать по влиянию до оплаты; отдельный порог выбытия соперника (например 0.15). Потенциал после исправления — около 67 % на M30, путь придётся перенастроить.
- **Ф5. Недовольство при Репрессиях 4–6 — храповая петля.** Варианты: UNREST_DECAY 2 → 3 (проверено, «1984» не задето) или убывание лидеров при недовольстве < 40 (сейчас «мёртвая зона» 30–40).
- **Ф6. Требования проверяются только при стройке и старте исследования.** После Репрессий 7 можно откатить Слежку, после C3 — Слежку 6 → 5. Нужно решение, допустимо ли.
- **Ф7. Репутация упирается в 100** к M12–M24 у всех без грязи; порог CLEAN_MIN_REPUTATION 90 поэтому не работает.

## Баги ядра и тестовых помощников
1. **Соперник не выбывает по репутации ≤ 0 (§6.6).** Шаг 7.8 `rivalMonthlyDrift` прибавляет `0.05·(rep_start − rep)` до проверки 7.11 `quarterEnd` (`r.reputation <= 0`); ветка мертва. Воспроизведение: `npx tsx sim/repro-rival-zero.ts` → `day 90 police alive true rep 2.25`. Исправление: проверять при изменении или до дрейфа.
2. **Шанс поглощения считается по влиянию после списания 30** (`tickTasks` → `absorbChance(s.influence, …)`). Вопрос к gdd-designer, тот ли это смысл §6.3.
3. **`testing/honest-bot.ts`:** `autoChoice` берёт «разогнать» у митинга и «шантажировать» у квеста «Сенатор» (грязное действие у честного бота); найм при `budget > 1200` без оглядки на план и теракты при любом шансе дают 45 % банкротств.
