# Шаблон: варианты карточек шанса

Для `content-filler`. Тон: сатира в подаче, механика всерьёз (ГДД §1). Сухая бюрократическая ирония, без мата, без шуток над жертвами насилия.

## Куда писать
Только в `src/lib/content/cards/variants.json` (массив). Файл **не подключён** к `index.ts`: карточки попадут в игру после одобрения `gdd-designer` и `balance-analyst`. Не правь `chance.json` (там 11 встроенных карточек, их механику держит ядро) и не дублируй существующие `id`/названия: сначала прочитай обе папки.

## Формат (строго по `ChanceCardContentSchema`)
```json
{
  "id": "snake_case_latin",
  "title": "до 60 знаков",
  "body": "до 60 слов, русский; последним предложением явно назван эффект (кому, на сколько, на какой срок)",
  "tone": "positive | negative | neutral",
  "mechanics": {
    "weight": 4,
    "effects": [ { "kind": "reputation", "target": "player", "value": 3 } ],
    "requires": []
  }
}
```
Для новой карточки `mechanics` обязательна. Для встроенных `id` её быть не должно.

## Допустимые эффекты (закрытый набор) и диапазоны
Выходить за диапазон нельзя. Единицы: репутация, влияние, засвеченность, следствие, недовольство - пункты шкалы 0-100; бюджет - k$ (месячный бюджет игрока около 700-1500 k$, старт 1500).

| kind | Поля | Диапазон для массовки |
|---|---|---|
| `reputation` | `target` (`player` / `all` / `random_rival` / `police` / `cia` / `secret_service`), `value` | от -10 до +6 (встроенные: -10, -8, -5, +6) |
| `influence` | `target`, `value` | от -8 до +5 |
| `exposure` | `value` | от -10 до +15 |
| `investigation` | `value` | от -10 до +10 |
| `unrest` | `value` | от -10 до +10 |
| `budget` | `value` (целое, k$) | от -300 до +300 (встроенная награда: 300) |
| `incomeMult` | `value`, `months` | 0.85-1.10, 3-6 месяцев (встроенные: 0.85/6, 1.10/3) |
| `rivalPlan` | `target`, `value` | от -0.20 до +0.20 (встроенный: 0.2) |
| `hearings` | - | только в негативных карточках; не более 1 такой карточки на 4 варианта |
| `spawnCase` | `caseKind`, `difficulty` 1-5, `timerDays` 1-90 или `null`, `rewardMult` 0-5 | сложность 3-4, таймер 15-30, награда ×1-2 (встроенное: d4, ×2) |
| `planTargetMult` | `value` | 0.8-1.2 |

Правила:
1. Эффектов в карточке от 1 до 3. Суммарно карточка должна быть «справедливой»: позитивные без негативных побочек допустимы только если `weight` 4-6; негативные имеют вес 6-10.
2. `weight`: 4-10 (встроенные - от 6 до 10). Редкие и сильные эффекты - 4-5.
3. `requires` - из набора: `minSurv` (0-6), `minRepr` (0-7), `minDept` (`dept`, 0-5), `minExposure`, `maxExposure` (0-100), `tech` (A1..C3), `rivalAlive`, `minMonth` (1-60). Если эффект бьёт по конкретному сопернику, обязательно `rivalAlive` для него.
4. Если карточка обращается к конкретному живому сопернику, в тексте он назван по-русски: «Полиция», «ЦРУ», «Секретная служба».
5. Никаких новых видов эффектов. Если идея требует иного (например, «агент получает лояльность +10»), не придумывай: оставь поле `body` без этой идеи и в конце файла (в отдельном файле `cards/TODO.md`) добавь строку `TODO(core): <идея>`.

## Тон и запреты
- Заголовок - информационный, как в сводке. Тело - сухо, одна ирония на карточку.
- Реальные ведомства использовать можно; **реальные живые люди** - нет. Только вымышленные персонажи (указывай должность, не имя).
- Запрещено: цифры в тексте, не совпадающие с `mechanics`; оценки реальных политических партий; графические описания насилия; мемы и сленг дольше года.
- Не повторять шутку о «папке», «отчёте» или «кофе» больше одного раза на пять карточек.

## Эталоны
1. Позитив, один эффект:
```json
{ "id": "charity_gala", "title": "Благотворительный вечер", "body": "Ведомство пригласили на ужин в пользу сирот и налогов. Фотографии получились удачными, меню нет. Репутация +3.", "tone": "positive",
  "mechanics": { "weight": 5, "effects": [ { "kind": "reputation", "target": "player", "value": 3 } ], "requires": [ { "kind": "minDept", "dept": "pr", "value": 1 } ] } }
```
2. Негатив с двумя эффектами:
```json
{ "id": "audit_surprise", "title": "Внеплановая проверка счётной палаты", "body": "Проверяющие пришли с вопросами и без предупреждения. Нашли немного, но этого хватило для заметки. Репутация -4, следствие +5.", "tone": "negative",
  "mechanics": { "weight": 7, "effects": [ { "kind": "reputation", "target": "player", "value": -4 }, { "kind": "investigation", "value": 5 } ], "requires": [] } }
```
3. Нейтраль с делом:
```json
{ "id": "bank_cluster", "title": "Серия ограблений банков", "body": "Три банка за неделю, один почерк и одинаковые сумки. Появилось дело сложности 3 с наградой ×1.5, срок 25 дней.", "tone": "neutral",
  "mechanics": { "weight": 6, "effects": [ { "kind": "spawnCase", "caseKind": "regular", "difficulty": 3, "timerDays": 25, "rewardMult": 1.5 } ], "requires": [ { "kind": "minMonth", "value": 3 } ] } }
```
4. Против соперника:
```json
{ "id": "cia_budget_row", "title": "ЦРУ поссорилось с казначейством", "body": "Управление не смогло объяснить крупную статью расходов, и объяснять придётся долго. Репутация ЦРУ -6.", "tone": "positive",
  "mechanics": { "weight": 5, "effects": [ { "kind": "reputation", "target": "cia", "value": -6 } ], "requires": [ { "kind": "rivalAlive", "rival": "cia" } ] } }
```
5. Экономика:
```json
{ "id": "grant_season", "title": "Сезон грантов", "body": "Фонды раздали деньги, не прочитав заявки. Бюджет +150 k$ единовременно.", "tone": "positive",
  "mechanics": { "weight": 4, "effects": [ { "kind": "budget", "value": 150 } ], "requires": [] } }
```

## Проверка перед сдачей
Файл должен проходить `ChanceCardContentSchema` (тест `content.test.ts` проверяет `cards/variants.json`, если он есть). В теле карточки должно быть до 60 слов, `id` уникальны и не совпадают с `chance.json`.
