# Шаблон: трейты агентов

Для `content-filler`. Тон: сатира в подаче, механика всерьёз. Трейт - короткая черта характера, которую игрок читает при найме.

## Куда писать
Только в `src/lib/content/traits-variants.json` (массив). Файл **не подключён** к `index.ts`: новые трейты влияют на баланс, поэтому подключает их оркестратор после одобрения `gdd-designer` и `balance-analyst`. Не правь `traits.json` (шесть встроенных трейтов: `corrupt`, `hero`, `blabbermouth`, `workaholic`, `idealist`, `with_past`; их механику держит ядро).

## Формат (строго по `TraitContentSchema`)
```json
{
  "id": "snake_case_latin",
  "name": "до 20 знаков, русский",
  "description": "1-2 предложения, до 40 слов; в конце явно названа механика числами",
  "mechanics": { "weight": 10, "modifiers": [ { "kind": "opChance", "opType": "all", "value": 0.03 } ] }
}
```
`mechanics` обязательна для новых трейтов.

## Допустимые модификаторы и диапазоны
| kind | Поля | Диапазон для массовки |
|---|---|---|
| `opChance` | `opType` (`investigation` / `terror` / `infiltration` / `surveillance` / `all`), `value` | от -0.05 до +0.05 (встроенные: +0.05); для `all` не более ±0.03 |
| `loyaltyPerMonth` | `value` | от -2 до +1 (встроенные: -2, +1) |
| `exposurePerOp` | `value` | от -1 до +2 (встроенный: +1) |
| `defectMult` | `value` | 0.5-2 (встроенный `corrupt` даёт ×2) |
| `noOverwork` | - | не комбинировать с `loyaltyPerMonth` > 0 |
| `forbidDirty` | - | только вместе с позитивным модификатором (`opChance` > 0) |

Правила:
1. Каждый трейт - от 1 до 2 модификаторов; один плюс и один минус - норма. Чисто позитивный трейт должен иметь `weight` ≤ 8, чисто негативный - не меньше 15.
2. `weight`: 5-20 (встроенные: 20, у `with_past` генерируется отдельно).
3. Не придумывай других видов модификаторов. Идеи, которые не помещаются в таблицу, пиши в `traits/TODO.md` как `TODO(core): <идея>`.
4. Не повторяй встроенные: «Болтун», «Герой», «Идеалист» и т.д. - уже есть.

## Тон и запреты
- Название - одно-два слова, как в досье. Описание: бюрократическая ирония и конкретика (что именно этот агент делает странного).
- Нельзя: уничижительные ярлыки по национальности, полу, возрасту, здоровью, религии; медицинские диагнозы как шутка; реальные люди.
- Числа в описании обязаны совпадать с модификаторами.
