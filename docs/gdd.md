## 0. Соглашения (обязательны для ядра)

| Обозначение | Смысл |
|---|---|
| `clamp(x, a, b)` | `Math.min(b, Math.max(a, x))` |
| `roll(p)` | одно обращение к RNG: `rng.next() < p`. При `p ≤ 0` RNG **всё равно** вызывается (чтобы порядок вызовов не зависел от значений) и результат `false` |
| `randInt(a, b)` | целое из `[a, b]` включительно, равномерно |
| `randFloat(a, b)` | вещественное из `[a, b)` |
| `pickWeighted(list)` | выбор по весам; при нулевой сумме весов действие не выполняется, но один вызов RNG тратится |
| `round(x)` | `Math.round(x)` |
| `[cond]` | 1, если условие истинно, иначе 0 |

- **Траты по решению игрока** (найм, обучение, медали, стройка, исследования, действия против конкурентов, платные варианты квестов) доступны только при `budget >= cost`; иначе вариант неактивен.
- **Кредит на операции** (§2.7): запуск операции (`investigation`, `terror`, `infiltration`, `surveillance`) разрешён, пока `budget − cost >= −credit_limit`.
- Кроме этого, в минус бюджет уводят только автоматические списания (зарплаты и содержание в конце месяца, проценты по кредиту) и принудительные штрафы событий (например, кража «Коррупционера»).
- **Деньги** хранятся в целых k$ (тысячи долларов), в UI показываются как «$ тыс.» / «$ млн». После любого умножения результат округляется через `round`.
- **Шкалы 0–100** (репутация, влияние, засвеченность, контроль, недовольство, под следствием, лояльность, влияние лидера) хранятся как float без округления и клампятся в `[0, 100]` **после каждого** изменения. UI показывает `Math.floor`. Сравнения с порогами идут по точному float.
- **Вероятности** — доли `[0, 1]`.
- **Время**: целые игровые дни. Месяц = `DAYS_PER_MONTH` (30) дней, год = 12 месяцев, срок = `TERM_MONTHS` (60) месяцев = 1800 дней. День `d` = 1..1800, месяц `m = ceil(d / 30)` = 1..60, квартал `Q = ceil(m / 3)` = 1..20, индекс квартала `q = Q − 1`. Конец месяца — это день, где `d % 30 == 0`.
- **Длительности** с множителями округляются вверх: `ceil`, минимум 1 день.
- **RNG** один, сидированный, его состояние лежит в `GameState`. Порядок вызовов задаёт порядок обработки (§3.3) и порядок сущностей: по возрастанию `id`. Соперники обходятся в фиксированном порядке `police → cia → secret_service`.

## 1. Концепция

| Параметр | Значение |
|---|---|
| Жанр | Менеджер/стратегия в реальном времени с паузой |
| Ведомство игрока | ФБР. В v1 **только ФБР**; ЦРУ и Моссад — после релиза |
| Соперники (для ФБР) | Полиция, ЦРУ, Секретная служба |
| Тон | Сатира в подаче (тексты, названия, карточки) при серьёзных механиках |
| Платформа | Веб, браузер, сначала десктоп; SvelteKit, Vercel (§11) |
| Длительность партии | 60 игровых месяцев = срок директора; ≈ 90 мин на ×1 без пауз |
| Режим | Одиночная игра против ИИ, песочница без сюжетной кампании |

**Цель:** выполнить одно из 5 условий победы (§8) раньше конца срока. Победа завершает партию сразу. Исключение — «Чистые руки»: эта победа проверяется только в конце срока.
**Поражение:** §8.6. Коды поражений совпадают с полем `results.defeat_reason`.

### 2.2 Репутация

Ежемесячный дрейф (конец месяца):
```
reputation += -REP_MEAN_REVERT * (reputation - REP_ANCHOR)       // 0.03, к 50
reputation += PR_PASSIVE_REP * dept.pr                            // +0.3 за уровень пиара
```
**Мягкий потолок.** Любой **положительный** прирост репутации (разовый и пассивный от пиара, у игрока и у ИИ) при `reputation > REP_SOFTCAP_START` (70) умножается:
```
gain_mult = max(REP_GAIN_MIN_MULT, (100 - reputation) / (100 - REP_SOFTCAP_START))   // 0.1; при 80 → 0.67, 90 → 0.33, 95 → 0.17
```
Вместе с дрейфом к 50 честный игрок стабилизируется около 88–92, если стабильно раскрывает дела, а 100 почти недостижимо. Отрицательные изменения не масштабируются.
Разовые изменения перечислены в таблицах операций (§5.3), действий (§6.3), событий и карточек. Любая потеря репутации от **провала операции** умножается на `legal_mult = 1 - LEGAL_FAIL_REDUCTION * dept.legal` (0.08 за уровень). Пока активны Репрессии 6, она равна 0.

### 2.3 Засвеченность и скандалы

Ежемесячно (конец месяца, §3.3):
```
exposure += SURV_EXPOSURE_MONTHLY[surv_level]          // [0,0,0,0.5,1,2,4] для уровней 0..6
exposure += REPR_EXPOSURE_PER_LEVEL * repr_level       // 1 за уровень
exposure += UNREST_RIOT_LEAK_EXPOSURE * [unrest >= 80] // 5
exposure -= EXPOSURE_DECAY + EXPOSURE_DECAY_PER_PR * dept.pr   // 2 + 0.5*PR
exposure = clamp(exposure, 0, 100)
```
Бросок скандала (один раз в месяц, после пересчёта засвеченности):
```
p_scandal = exposure <= SCANDAL_EXPOSURE_FLOOR ? 0
          : clamp(SCANDAL_K * ((exposure - SCANDAL_EXPOSURE_FLOOR) / (100 - SCANDAL_EXPOSURE_FLOOR))^2, 0, SCANDAL_P_MAX)
// FLOOR = 10, K = 0.6, P_MAX = 0.6. Примеры: E=30 → 0.030, E=50 → 0.119, E=70 → 0.267, E=90 → 0.474
```
Нелинейность здесь намеренная: пока грязной работы немного, она почти бесплатна, но с какого-то момента риск начинает расти лавинообразно.

**Скандал** (если `roll(p_scandal)`):
```
rep_loss = (SCANDAL_REP_BASE + SCANDAL_REP_PER_EXPOSURE * exposure)    // 5 + 0.15*E
         * (1 - PR_SCANDAL_REDUCTION * dept.pr)                          // 0.1 за уровень
         * (repr_level >= 4 ? REPR_CENSORSHIP_SCANDAL_MULT : 1)          // 0.5
reputation -= rep_loss
if exposure >= SCANDAL_INVESTIGATION_THRESHOLD (50): investigation += SCANDAL_INVESTIGATION_PER_EXPOSURE * exposure * legal_inv_mult   // 0.1*E
if exposure >= HEARINGS_EXPOSURE_THRESHOLD (60): запускается «Слушания в Конгрессе» (§9.6)
exposure -= SCANDAL_EXPOSURE_RELEASE   // 10: «пар выпущен»
```

### 2.4 Влияние

Ежемесячно: `influence += -INFL_MEAN_REVERT * (influence - INFL_ANCHOR)` (0.03, к 20) и `+ NET_INFLUENCE_PER_LEVEL * Σ networks.level` (0.2).
Разовые изменения: перевыполнение плана (§5.5), теракт раскрыт (+`OP_TERROR_INFLUENCE` 3), «Работа с Конгрессом» (§6.3), шантаж (§9.5), слушания, выборы.
Если действие требует влияния, а его не хватает, действие недоступно.

### 2.5 Компромат

Компромат — не просто счётчик, а список предметов:
```
KompromatItem { id, target: { kind: 'rival'|'senator'|'president'|'leader', id }, strength: 1..3,
                acquiredDay, expiresDay | null, usedCooldownUntil: number | null }
```
- Предмет истекает через `KOMPROMAT_TTL_DAYS` (360). Исключение: при технологии C2 компромат на сенаторов не истекает. Компромат на президента теряет силу при смене администрации (§9.7).
- Сила компромата, добытого слежкой: `strength = 1 + [surv_level >= 3] + [surv_level >= 5]`.
- Счётчик «Компромат (шт.)» в UI = число непросроченных предметов.
- У соперников компромат на игрока — просто целое число `rival.kompromatOnPlayer` без силы.

### 2.6 Под следствием (дело против директора)

```
// каждый прирост:
investigation += raw_gain * legal_inv_mult,  где legal_inv_mult = 1 - LEGAL_INVESTIGATION_REDUCTION * dept.legal   // 0.1 за уровень
// ежемесячно:
investigation -= INVESTIGATION_DECAY + INVESTIGATION_DECAY_PER_LEGAL * dept.legal    // 1 + 0.5*Legal
```
- Порог `INVESTIGATION_FREEZE_THRESHOLD` (50): пока порог превышен, доход умножается на `INVESTIGATION_FREEZE_MULT` (0.8). При первом пересечении снизу вверх запускается событие «Допросы директора» (автопауза, информационное).
- Порог `INVESTIGATION_ARREST_THRESHOLD` (100) → немедленное поражение `arrested`.
- Защита описана в §6.5.

### 2.7 Кредит на операции
```
credit_limit = round(CREDIT_LIMIT_MONTHS * lastIncome)    // 1.0 × доход последнего месяца; до первого дохода — доход месяца 1 (§6.2)
// конец месяца, сразу после расходов (§3.3, шаг 7.2):
if budget < 0: budget -= round(CREDIT_INTEREST_RATE * (-budget))   // 5 % от долга
```
Кредит есть только у операций: они окупаются наградой при успехе. Правило банкротства (§8.6) не меняется — бюджет < 0 в конце месяца 3 месяца подряд. Зарплаты при бюджете < 0 по-прежнему считаются невыплаченными (§4.2.6).

## 3. Игровой цикл (реальное время)

### 3.1 Скорости
Один тик ядра = 1 игровой день. Адаптер переводит реальное время в дни: `DAY_MS_BY_SPEED = [3000, 1500, 1000]` мс на день для ×1/×2/×3. Срок на ×1 занимает 1800 × 3 с = 90 мин. Пауза: тики не идут, но игрок может отдавать приказы.

### 3.2 Календарь

| Что | Когда | Описание |
|---|---|---|
| Новые дела | Каждый день, бросок (§5.4) | Появляются на карте с таймером; не взял вовремя — дело уходит сопернику |
| Операции | Идут `duration` дней | Агенты заняты, прогресс-бар; можно усилить или отменить (§5.2) |
| Действия соперников | Каждые `AI_ACTION_INTERVAL_DAYS` дней у каждого | §6.4; игрок видит источник с шансом обнаружения |
| Зарплаты и расходы | Конец каждого месяца | Списываются автоматически |
| Карточки шанса | Раз в `randInt(CARD_INTERVAL_MIN_DAYS, CARD_INTERVAL_MAX_DAYS)` = 60–120 дней | Автопауза, окно карточки |
| Распределение бюджета | Конец каждого квартала (месяцы 3, 6, …, 60) | Итоги плана, пересчёт долей, автопауза с отчётом |
| Слушания | По событию | Скандал при E ≥ 60, план < 0.7, карточка |
| Выборы | Начало месяца `ELECTION_MONTH` (47) | §9.7 |

### 3.3 Порядок обработки дня (детерминирован)

1. `day += 1`.
2. Прогресс таймеров в порядке `id`: операции, обучение, стройка отделов и уровней слежки/репрессий, исследование, ордера, этапы квестов.
3. Завершение операций, у которых истёк таймер, в порядке `id`: бросок успеха, применение последствий.
4. Генерация дел (§5.4): если день — первый день месяца (`d % 30 == 1`), сначала создаются дела без таймера (Репрессии 3, «Информатор»), затем случайные. После этого истекают дела с таймером 0.
5. ИИ соперников, у которых `nextActionDay <= day` (§6.4), в порядке police → cia → secret_service.
6. Карточка шанса, если `day >= nextCardDay`.
7. Если `day % 30 == 0` — **конец месяца**:
   1. Доход: `budget += monthlyIncome` (§6.2).
   2. Расходы: зарплаты (§4.2.6), содержание штаба `HQ_UPKEEP`, отделов, уровней слежки и репрессий; затем проценты по кредиту (§2.7).
   3. Счётчик банкротства (§8.6).
   4. Лояльность всех агентов, затем броски перехода и крота (§4.2.7).
   5. Засвеченность и бросок скандала (§2.3).
   6. Недовольство, лидеры, контроль, протесты, бросок переворота (§4.4).
   7. Сети за рубежом: прогресс, провалы, двойной агент, добыча компромата (§9.1). Внедрённые агенты: добыча, раскрытие (§5.3).
   8. Дрейф репутации, влияния, спад «Под следствием».
   9. Истечение компромата.
   10. Обновление пула кандидатов (§4.2.2).
   11. Если `m % 3 == 0` — **конец квартала** (§5.5, §6.2, §6.6): план, проверка «рисования», распределение бюджета, изъятие остатка, проверка расформирования, коалиции, новые цели плана.
   12. Плановые события месяца (выборы).
8. Проверка поражений, затем побед (§8). Мгновенные поражения (`reputation <= 0`, `investigation >= 100`) проверяются ещё и сразу после любого изменения соответствующей шкалы.

### 3.4 Автопауза
По умолчанию игра ставит паузу на следующих событиях: карточка шанса; квартальный отчёт; слушания; любой шаг квеста с выбором (§9); выборы; победа или поражение; агент перешёл к врагу; провал сети; обнаружен крот; недовольство впервые перешло 50 или 80; «Под следствием» впервые перешло 50; первый месяц с бюджетом < 0.
В настройках можно отключить (флаги `autopause.*`): «просьба о прибавке», «дело скоро истечёт» (до истечения ≤ 3 дня, по умолчанию выключено), «операция завершена» (по умолчанию выключено).

## 4. Развитие ведомства

### 4.1 Отделы

Шесть отделов, уровни 0–5. На старте: Аналитика 1, Оперативный 1, остальные 0.
Стоимость перехода на уровень L: `DEPT_COST_BY_LEVEL[L-1]` = [80, 160, 320, 560, 900] k$ (до 5-го уровня в сумме 2020).
Стройка идёт `DEPT_BUILD_DAYS_PER_LEVEL * L` = 10·L дней. Каждый отдел строит не больше одного уровня за раз, разные отделы могут строиться параллельно. Эффект включается по завершении.
Содержание: `DEPT_UPKEEP_PER_LEVEL * level` = 20 k$ за уровень в месяц.

| Отдел (`key`) | Эффект за уровень | Требования |
|---|---|---|
| Аналитика `analytics` | Отдел операций «Расследование»: +`OP_DEPT_COEF` (0.03) к шансу; детектив: −1 подозреваемый на старте при уровне ≥ 3 | — |
| Оперативный `operations` | Отдел операций «Поимка террористов»: +0.03; +`AGENT_CAP_PER_OPS_LEVEL` (2) к лимиту агентов | L ≥ 3: Аналитика ≥ 2 |
| Кибер `cyber` | Отдел операций «Слежка»: +0.03; −`CYBER_LEAK_REVEAL_REDUCTION` (0.03) к шансу раскрытия источника слива; открывает уровни слежки (§4.3) | L ≥ 1: Аналитика ≥ 1; L ≥ 3: Аналитика ≥ 2 |
| Контрразведка `counterintel` | Отдел операций «Внедрение»: +0.03; −`CI_DEFENSE_PER_LEVEL` (0.06) к успеху враждебных действий ИИ; ×(1 − `CI_DEFECTION_REDUCTION` 0.12·L) к ежемесячному шансу перехода агента (вербовка крота считается только по общей формуле ИИ §6.4); обнаружение действий ИИ (§6.4) | L ≥ 1: Аналитика ≥ 1; L ≥ 3: Кибер ≥ 2 |
| Пиар `pr` | +0.3 репутации в месяц; −10 % потерь репутации от скандалов и сливов; +0.5 к спаду засвеченности; усиливает «Пиар-кампанию» | — |
| Юридический `legal` | −8 % последствий провалов (репутация и засвеченность); −10 % прироста «Под следствием»; +0.5 к его спаду; −2 дня ордера | — |

### 4.2 Персонал

#### 4.2.1 Агент
```
Agent { id, name, rank: 'novice'|'experienced'|'veteran', level: 1..5, xp,
        skills: { surveillance, combat, interrogation, hacking }  // 1..10
        loyalty: 0..100, salaryMult: 1 | 1.25 | 1.5, traits: TraitId[], perks: PerkId[],
        status: 'idle'|'on_op'|'training'|'abroad'|'embedded'|'protest_duty',
        moleFor: RivalId | null  // скрыто от игрока
        busyStreakDays, idleStreakDays, successesThisMonth, failsThisMonth, location: { stateId } | { countryId } | { rivalId } }
```
**Лимит агентов:** `agent_cap = AGENT_CAP_BASE + floor(JP / AGENT_CAP_JP_DIVISOR) + AGENT_CAP_PER_OPS_LEVEL * dept.operations`, где `JP = Σ по штатам (частичные = 1, полные = 2)` (§6.7). На старте: 4 + floor(60/10) + 2·1 = 12. При превышении лимита (после потери штатов) новых агентов нанимать нельзя, текущие остаются.

#### 4.2.2 Найм
Пул из `HIRE_POOL_SIZE` (5) кандидатов обновляется в конце каждого месяца, неразобранные пропадают. Ранг каждого кандидата: `pickWeighted(HIRE_RANK_WEIGHTS)` = novice 55 / experienced 33 / veteran 12.

| Ранг | Найм, k$ | Базовая зарплата, k$/мес | Навыки (каждый из 4) | Стартовая лояльность | Стартовый уровень |
|---|---|---|---|---|---|
| Новичок | `HIRE_COST_NOVICE` 50 | `SALARY_NOVICE` 25 | `randInt(1,3)` | `randInt(70,85)` | 1 |
| Опытный | `HIRE_COST_EXPERIENCED` 150 | `SALARY_EXPERIENCED` 50 | `randInt(4,6)` | `randInt(50,69)` | 2 |
| Ветеран | `HIRE_COST_VETERAN` 400 | `SALARY_VETERAN` 90 | `randInt(7,9)` | `randInt(20,80)` | 3 |

Одному случайному навыку кандидата добавляется +1 (кап 10), это его «профиль». Трейт выпадает с шансом `HIRE_TRAIT_CHANCE` (0.4), выбор `pickWeighted` из §4.2.5. Ветеран дополнительно получает трейт `with_past` («с прошлым») с шансом `VETERAN_PAST_CHANCE` (0.3). XP на старте равен порогу уровня.
**Стартовый состав:** 4 новичка и 2 опытных, сгенерированные тем же генератором без трейтов.
**Увольнение:** выходное пособие = 1 месячная зарплата; у остальных агентов лояльность −`FIRE_LOYALTY_PENALTY` (1).

#### 4.2.3 Опыт, уровни, перки
- XP за операцию: успех `XP_SUCCESS_BASE + XP_PER_DIFFICULTY * difficulty` (20 + 10·d), провал `XP_FAIL` (10). Обучение даёт `XP_TRAINING` (20).
- Пороги уровней: `XP_LEVEL_THRESHOLDS = [0, 100, 250, 450, 700]` (уровни 1..5).
- При повышении уровня: +1 к основному навыку последней операции (кап 10) и выбор 1 перка из ещё не взятых. Автоматический выбор (симулятор, ИИ) берёт первый подходящий по порядку таблицы.

| Перк (`id`) | Эффект |
|---|---|
| `cold_blooded` Хладнокровный | −0.05 к шансу провала на границе; +0.05 к шансу внедрения (§9.1) |
| `marksman` Стрелок | +0.05 к «Поимке террористов»; −0.05 к шансу гибели |
| `analyst` Аналитик | +0.05 к «Расследованию» |
| `ghost` Призрак | засвеченность от операций с его участием ×0.5 |
| `mentor` Наставник | остальные агенты в команде получают XP ×1.5 |
| `iron_will` Железный | лояльность не опускается ниже 40 |
| `negotiator` Переговорщик | +0.10 к шансам тактик допроса |
| `netrunner` Нетраннер | +0.05 к «Слежке» |

Бонусы перков **и трейтов** (включая контентные) к шансу операции **не складываются** между агентами: для каждого `id` перка или трейта берётся максимальный бонус в команде. Пример: два «Героя» на теракте дают +0.05, «Герой» и «С прошлым» вместе — +0.10. Эффекты, которые не являются бонусом к шансу (засвеченность «Болтуна», кража «Коррупционера», лояльность), применяются к каждому агенту отдельно. Множитель «Призрака» ×0.5 применяется один раз, если в команде есть хотя бы один такой агент.

#### 4.2.4 Обучение
Агент на время курса в статусе `training`, недоступен.

| Курс | Дней | Цена, k$ | Эффект |
|---|---|---|---|
| Навык (слежка/бой/допрос/хакинг) | `TRAINING_SKILL_DAYS` 20 | `TRAINING_SKILL_COST` 40 | +1 к навыку; обучением навык поднимается максимум до `TRAINING_SKILL_CAP` (8) |
| Язык страны X | `TRAINING_LANGUAGE_DAYS` 30 | `TRAINING_LANGUAGE_COST` 40 | В стране X: шанс провала на границе −0.03, прогресс сети ×1.1 |
| Легенда | `TRAINING_LEGEND_DAYS` 20 | `TRAINING_LEGEND_COST` 30 | +0.05 к внедрению (одноразово, на ближайшую заброску) |

Каждый курс даёт +20 XP.

#### 4.2.5 Трейты

| Трейт (`id`) | Вес выпадения | Эффект |
|---|---|---|
| `corrupt` Коррупционер | 20 | Лояльность −2 в месяц; раз в месяц `roll(0.05)` → −20 k$ и засвеченность +2; шанс стать кротом ×2 |
| `hero` Герой | 20 | +0.05 к «Поимке террористов»; при успехе с его участием репутация +1; нельзя назначить на грязные действия (§6.3) и внедрение в соперника |
| `blabbermouth` Болтун | 20 | +1 засвеченности за каждую операцию с его участием |
| `workaholic` Трудоголик | 20 | Нет штрафа за переработку |
| `idealist` Идеалист | 20 | Лояльность +1 в месяц; −10 лояльности, если ведомство совершило грязное действие в этом месяце (разово) |
| `with_past` С прошлым | только ветераны | +0.05 к шансу всех операций; при найме случайный соперник получает +1 `kompromatOnPlayer` |

Контент может добавлять трейты только через zod-схему, где эффекты задаются из закрытого набора модификаторов (это зона core-architect).

#### 4.2.6 Зарплата
```
salary(agent) = round(BASE_SALARY[rank] * (1 + SALARY_LEVEL_STEP * (level - 1)) * salaryMult)   // STEP = 0.05
```
`BASE_SALARY[rank]` = `SALARY_NOVICE` / `SALARY_EXPERIENCED` / `SALARY_VETERAN`.
`salaryMult` ∈ {1, 1.25, 1.5} — «зарплата выше рынка», устанавливает игрок.
Если на момент списания зарплат `budget < 0` (после поступления дохода), все зарплаты месяца считаются **невыплаченными**: деньги всё равно списываются (бюджет уходит глубже в минус), но каждый агент получает −10 к лояльности вместо +1.

#### 4.2.7 Лояльность
Конец месяца, для каждого агента:
```
Δ = (paid ? LOYALTY_PAID : LOYALTY_UNPAID)                         // +1 / -10
  + LOYALTY_SALARY_BONUS[salaryMult]                               // 1→0, 1.25→+2, 1.5→+4
  + LOYALTY_PER_SUCCESS * successesThisMonth                       // +3
  - LOYALTY_PER_FAIL * failsThisMonth                              // 5
  - LOYALTY_OVERWORK * [busyStreakDays >= OVERWORK_STREAK_DAYS && !workaholic]   // 3, порог 60 дней без отдыха
  + трейты (corrupt −2, idealist +1)
loyalty = clamp(loyalty + Δ, iron_will ? 40 : 0, 100)
```
`busyStreakDays` — сколько дней подряд агент был не `idle`. Счётчик обнуляется после `OVERWORK_REST_DAYS` (5) дней подряд в `idle`.
Разово: награда «Медаль» (`MEDAL_COST` 20 k$, +`MEDAL_LOYALTY` 10, одному агенту не чаще раза в `MEDAL_COOLDOWN_DAYS` 180); операция с подставой агента (§6.5 «козёл отпущения») даёт −5 всем остальным.

| Лояльность | Эффект |
|---|---|
| 70–100 | Надёжен. При поимке за рубежом сеть не теряет уровней |
| 40–69 | Обычный режим. Раз в месяц `roll(RAISE_REQUEST_CHANCE)` (0.08) → мини-квест «Просит прибавку»: принять (`salaryMult` +0.25, максимум 1.5; лояльность +10) или отказать (лояльность −10) |
| 20–39 | Каждый месяц `roll(DEFECT_CHANCE_LOW × ci_mult)` (0.03) → переход. Доступен для вербовки кротом (§6.4). При поимке за рубежом сеть −1 |
| 0–19 | Каждый месяц `roll(DEFECT_CHANCE_CRITICAL × ci_mult)` (0.10) → переход. При поимке за рубежом сдаёт всю сеть (уровень → 0) |

`ci_mult = 1 − CI_DEFECTION_REDUCTION × dept.counterintel`; для `corrupt` шанс ×2. На вербовку крота `ci_mult` не действует.
**Переход:** агент удаляется. Случайный живой соперник получает +`DEFECTOR_KOMPROMAT` (2) `kompromatOnPlayer`. Если агент был за рубежом, сеть страны −1 уровень. Создаётся запись `defectors[]`; через `randInt(90, 360)` дней с шансом `DEFECTOR_RETURN_CHANCE` (0.25) он выходит на связь (квест «Перебежчик», §9.5) или становится лидером-архетипом «Бывший агент» (если недовольство > `DEFECTOR_LEADER_MIN_UNREST` = 40). Выбор: если недовольство > 40, то `roll(DEFECTOR_LEADER_CHANCE)` (0.5) → лидер, иначе квест; если недовольство ≤ 40 — всегда квест.
Потерянный агент (погиб, пойман, перешёл) не возвращается. Единственное исключение — квест «Перебежчик».

### 4.3 Ветка слежки

Уровни 0–6, повышаются строго по порядку. Стройка длится `SURV_BUILD_DAYS_PER_LEVEL * L` (15·L) дней. Содержание: `SURV_UPKEEP_PER_LEVEL * level` (15 k$/ур/мес). Откат на 1 уровень вниз бесплатный и мгновенный, но **запрещён**, если новый уровень слежки ниже требования какого-то активного уровня репрессий (`REPR_REQUIREMENTS`): сначала нужно откатить репрессии. Изученные технологии — знание, они не пропадают и откат не блокируют. Их требования проверяются только при старте исследования.

| Ур. | Источник данных | Цена, k$ `SURV_COST_BY_LEVEL` | Требует | Эффект | Засвеченность/мес `SURV_EXPOSURE_MONTHLY` |
|---|---|---|---|---|---|
| 1 | Открытые источники | 50 | — | +0.02·ур к «Расследованию» (накопительно, `SURV_INVEST_BONUS_PER_LEVEL`) | 0 |
| 2 | Базы госорганов | 100 | Кибер 1 | Длительность «Расследования» ×0.9 (`SURV_L2_DURATION_MULT`); детектив: «Запрос данных» доступен | 0 |
| 3 | Камеры и распознавание лиц | 200 | Кибер 2 | Таймер новых дел +5 дней (`SURV_L3_CASE_TIMER_BONUS`); сила компромата +1 | 0.5 |
| 4 | Метаданные и геолокация | 350 | Кибер 3 | +0.10 к «Слежке» (`SURV_L4_SURVEILLANCE_BONUS`); детектив: «Запрос данных» отсекает 2 | 1 |
| 5 | Запросы к техкомпаниям | 500 | Кибер 4 | Цель «сенатор» для «Слежки» (цель «президент» — только при C3 и Слежке 6, §8.5); сила компромата +1; в колоду попадает карточка «Утечка программы» | 2 |
| 6 | Массовая слежка без ордера | 800 | Кибер 5, технология A2 | Добыча компромата ×2 (2 предмета за успех); ордер не нужен | 4 |

**Ордер.** Операции «Слежка» начинаются после ордера длительностью `max(WARRANT_MIN_DAYS, WARRANT_BASE_DAYS - WARRANT_DAYS_PER_LEGAL * dept.legal)` = max(2, 10 − 2·Юр) дней. На это время агенты уже заняты. При Слежке 6 ордер не нужен. Для целей «сенатор» и «президент» ордер не оформляется (такое не санкционирует ни один суд), но за каждую попытку засвеченность +`ILLEGAL_TARGET_EXPOSURE` (12).
Уровни ≥ 3 считаются грязными для «Чистых рук» (§8.4).

### 4.4 Ветка репрессий

#### 4.4.1 Уровни
Требования уровней в машинном виде — `REPR_REQUIREMENTS` (Приложение A.8). Предыдущий уровень требуется всегда.
Уровни 0–7 строго по порядку. Включение уровня L стоит `REPR_COST_BY_LEVEL[L-1]` = [80, 160, 240, 320, 400, 480, 560] k$ (в сумме 2240) и идёт `REPR_BUILD_DAYS` (15) дней. Содержание: `REPR_UPKEEP_PER_LEVEL * repr_level` (20 k$/ур/мес). При включении уровня недовольство растёт разово на величину из таблицы.

| Ур. | Название | Эффект | Контроль `REPR_CONTROL` | Недовольство разово `REPR_UNREST_ON_ENABLE` | Требует |
|---|---|---|---|---|---|
| 1 | Списки неблагонадёжных | +0.03 к «Расследованию» (`REPR_L1_INVEST_BONUS`) | 5 | 2 | Слежка 2 |
| 2 | Профилактические беседы | Цель плана ×0.95; протестов −1 (минимум 0) | 10 | 5 | Слежка 2 |
| 3 | Сеть информаторов | +`REPR_L3_EXTRA_CASES` (2) дел в месяц без таймера; каждый месяц `roll(0.5)` → +1 компромат силы `REPR_L3_KOMPROMAT_STRENGTH` (1) (цель: случайный лидер или соперник) | 15 | 8 | Слежка 3 |
| 4 | Цензура и блокировки | Потери репутации от скандалов ×0.5 | 15 | 12 | Пиар 2 |
| 5 | Задержания без суда | Открывает «Задержать» в квестах; действие «Убрать лидера»: лидер удаляется, недовольство +5, засвеченность +5 | 20 | 20 | Юротдел 3 |
| 6 | «Министерство правды» | Провалы операций не снижают репутацию | 25 | 15 | Слежка 5 |
| 7 | «Полиция мыслей» | Потолок недовольства `REPR_L7_UNREST_CAP` (30): избыток сверх 30 убывает на `REPR_L7_UNREST_DRAIN` (5) в месяц, выше 30 недовольство не растёт; протесты невозможны | 30 | 0 | Уровни 1–6, Слежка 6, технология A3 |

#### 4.4.2 Контроль
```
control = clamp( Σ REPR_CONTROL[1..repr_level] + control_bonus - max(0, unrest - CONTROL_UNREST_PIVOT), 0, 100 )   // PIVOT = 50
```
`control_bonus` даёт «Разогнать митинг» (+5); он убывает на `CONTROL_BONUS_DECAY` (1) в месяц до 0.
Контроль снижает цель плана: `plan_target × (1 − CONTROL_PLAN_REDUCTION × control / 100)` (0.3 при контроле 100).
Сумма Σ для уровней 1..6 равна 90, для 1..7 — 120. Поэтому контроль 100 возможен только на 7-м уровне и при недовольстве ≤ 70.

#### 4.4.3 Недовольство
Ежемесячно:
```
unrest += REPR_UNREST_MONTHLY_PER_LEVEL * repr_level                // 0.5
unrest += Σ_leaders LEADER_UNREST_COEF * leader.influence * (archetype == rights ? LEADER_RIGHTS_UNREST_MULT : 1)   // 0.02 (лидер 100 → +2); правозащитник ×0.5
unrest -= UNREST_DECAY                                               // 3
unrest = clamp(unrest, 0, 100)
if repr_level == 7:
    if unrest_before > REPR_L7_UNREST_CAP: unrest = max(REPR_L7_UNREST_CAP, unrest_before - REPR_L7_UNREST_DRAIN)  // приросты игнорируются, только дренаж
    else: unrest = min(unrest, REPR_L7_UNREST_CAP)
```
`unrest_before` — значение в начале этого шага. При Репрессиях 7 любое **разовое** увеличение недовольства (квесты, события) обрезается: `unrest_new = min(unrest_new, max(REPR_L7_UNREST_CAP, unrest_old))`.
**Откат.** Любой уровень можно откатить мгновенно и бесплатно (откат слежки ограничен, §4.3). Контроль пересчитывается сразу, недовольство само не падает и уходит только через `UNREST_DECAY`. Если за `THAW_WINDOW_DAYS` (30) откачено ≥ 2 уровней, запускается событие **«Оттепель»**: недовольство −15, засвеченность +10, «Под следствием» +10.

#### 4.4.4 Пороги

| Недовольство | Эффект (проверяется в конце месяца) |
|---|---|
| ≥ 50 | Протесты: `n = 1 + floor((unrest − 50) / 10)` (минус 1 при Репрессиях 2). `n` свободных агентов переводятся в `protest_duty` на месяц. Если свободных не хватает, за каждого недостающего репутация −2 |
| ≥ 80 | Бунты: засвеченность +5/мес (массовые утечки). Бросок переворота `p = clamp(COUP_COEF * (unrest − COUP_UNREST_PIVOT) / COUP_UNREST_STEP, 0, COUP_P_MAX)` (0.02·(U − 75)/5; максимум 0.10); успех → поражение `riot` |
| Репрессии ≥ 1 | Засвеченность +1·уровень/мес (§2.3); у сетей за рубежом шанс провала +0.005·уровень (§9.1) |

#### 4.4.5 Лидеры сопротивления
- Появление: в конце месяца, если `unrest > 40` и `leaders.length < min(LEADER_MAX, 1 + floor((unrest − 40) / 20))` (`LEADER_MAX` = 3), то `roll(LEADER_SPAWN_CHANCE)` (0.3). Штат выбирается случайно, архетип — `pickWeighted` (равные веса; «Бывший агент» доступен только при наличии `defectors[]`).
- Стартовое влияние `LEADER_START_INFLUENCE` = 20 (блогер 30).
- Ежемесячно: при `unrest ≥ 40` влияние +`LEADER_GROWTH` (4; блогер 6), при `unrest < LEADER_DECLINE_BELOW_UNREST` (40) влияние −4 (мёртвой зоны нет). Лидер с влиянием 0 исчезает.
- Влияние достигло 100: `roll(LEADER_PEAK_PROTEST_CHANCE)` (0.5) — общенациональный протест (недовольство +10, засвеченность +5), иначе лидер поддерживает случайного живого соперника (его влияние +10). Влияние лидера сбрасывается до 70.
- Пока лидер в штате, забастовка: дела в этом штате не появляются, если лидер — «Профсоюзный лидер» с влиянием ≥ 50.
- Квест архетипа (§9.5) срабатывает при появлении лидера и один раз при пересечении влияния 60.

| Архетип | Сила (механика) | Слабость (механика) |
|---|---|---|
| Правозащитник | Пока жив: засвеченность +0.5/мес | Мало сторонников на улице: его вклад в рост недовольства ×`LEADER_RIGHTS_UNREST_MULT` (0.5) |
| Блогер-разоблачитель | Рост +6/мес | «Дискредитировать» с шансом 0.7 вместо 0.5 |
| Профсоюзный лидер | Забастовки (см. выше) | Уступка снижает его влияние на 30 |
| Бывший агент | При появлении сеть в случайной стране −1 | Квест «Суд по старому делу» |

### 4.5 Дерево технологий
Три ветки по 3 технологии. Внутри ветки — строго по порядку. В каждый момент идёт **одно** исследование.
Состав и требования в машинном виде — `TECH_TREE` (Приложение A.9). Цена и срок по ярусу: `TECH_COST_BY_TIER` = [300, 600, 1000] k$, `TECH_DAYS_BY_TIER` = [60, 90, 120]. Полная ветка = 1900 k$ и 270 дней.
**Правило вершины:** исследовать можно только **одну** технологию 3-го яруса за партию. После начала исследования вершины остальные вершины блокируются, а при отмене блок снимается.
**Отмена исследования:** возвращается `round(RESEARCH_CANCEL_REFUND * цена)` (0.5), прогресс теряется.

| Ветка | Ярус 1 | Ярус 2 | Ярус 3 (вершина → путь) |
|---|---|---|---|
| A. Внутренний контроль | A1 «Аналитика больших данных»: +0.05 к «Расследованию». Требует Слежка 2 | A2 «Предиктивный надзор»: +1 дело в месяц; открывает Слежку 6 | A3 «Доктрина тотального контроля»: открывает Репрессии 7 → «1984». Требует Репрессии 6 |
| B. Внешняя разведка | B1 «Школа нелегалов»: открывает заброску (§9.1), потолок сети 2 | B2 «Резидентуры»: потолок сети 3, прогресс сети ×1.25. Требует Контрразведка 1 | B3 «Сеть влияния»: потолок сети 5 → «Тень над регионом» |
| C. Тайная политика | C1 «Чёрная касса»: цена грязных действий ×0.7, засвеченность от них ×0.75. Требует Кибер 1 | C2 «Досье на элиту»: +0.15 к «Слежке» за сенаторами, компромат на сенаторов не истекает | C3 «Рычаги на президента»: открывает цель «президент» → «Серый кардинал». Требует Слежка 6 |

Без ветки B потолок сети равен 0: зарубежных операций нет.

## 5. Операции

### 5.1 Типы

| Тип (`key`) | Цена, k$ | Агентов (мин.) | Дней | Базовый шанс | Основной навык агента | Отдел | Цель |
|---|---|---|---|---|---|---|---|
| Расследование `investigation` | 30 | 2 | 30 | 0.60 | max(допрос, слежка) | Аналитика | Дело на карте |
| Поимка террористов `terror` | 100 | 4 | 30 | 0.40 | бой | Оперативный | Дело-теракт на карте |
| Внедрение агента `infiltration` | 60 | 1 | 40 | 0.45 | слежка | Контрразведка | Соперник (сложность 3) или движение лидера (2) |
| Слежка `surveillance` | 25 | 1 | 15 (+ордер) | 0.65 | max(слежка, хакинг) | Кибер | Соперник 3, лидер 2, сенатор 3–5 (по сопротивлению), президент 5 |

Сложность слежки за сенатором: `clamp(OP_TARGET_DIFFICULTY.senator + resistance − SENATOR_RESISTANCE_PIVOT, 1, 5)` = 4 + (сопротивление − 2). Сопротивление сенатора задаёт контент, а если не задал — `randInt(SENATOR_RESISTANCE_RANGE)` (1..3) на старте партии, по сенаторам в порядке `id`.
Константы: `OP_COST`, `OP_AGENTS_REQUIRED`, `OP_DURATION_DAYS`, `OP_BASE_CHANCE` (словари по ключу типа).
Можно назначить до `OP_MAX_EXTRA_AGENTS` (2) агентов сверх минимума (подкрепление).

### 5.2 Формула шанса успеха
Шанс считается в момент завершения по итоговому составу команды:
```
team_skill = max по агентам команды от primarySkill(agent, type)
team_level = среднее арифметическое level агентов команды (float)
extra      = Σ по агентам сверх минимума (не более 2): 1, если присоединился до 50% прогресса, иначе 0.5

p = clamp(
      OP_BASE_CHANCE[type]
    + OP_SKILL_COEF * (team_skill - OP_SKILL_PIVOT)          // 0.04 * (skill - 5)
    + OP_DEPT_COEF  * dept[OP_DEPT[type]]                    // 0.03 за уровень
    + OP_LEVEL_COEF * (team_level - 1)                       // 0.02
    + OP_REINFORCE_BONUS * extra                             // 0.04
    - OP_DIFFICULTY_COEF * (difficulty - 1)                  // 0.06
    + bonus                                                   // таблица ниже
    - OP_MOLE_PENALTY * [в команде есть крот]                 // 0.10
  , OP_CHANCE_MIN, OP_CHANCE_MAX)                            // 0.05 .. 0.95
```
| Бонус | Тип | Значение |
|---|---|---|
| Уровень слежки | investigation | `SURV_INVEST_BONUS_PER_LEVEL * surv_level` (0.02·ур) |
| Слежка ≥ 4 | surveillance | +0.10 |
| A1 | investigation | +`TECH_A1_INVEST_BONUS` 0.05 |
| C2 | surveillance, цель сенатор | +`TECH_C2_SENATOR_BONUS` 0.15 |
| Репрессии ≥ 1 | investigation | +0.03 |
| Перки (максимум по команде на каждый вид) | по таблице §4.2.3 | |
| Трейты `hero` (terror), `with_past` (все) | | +0.05 |

Пример, месяц 1: опытный (навык 5, уровень 2) + новичок (уровень 1) на деле сложности 3, Аналитика 1: `0.60 + 0 + 0.03 + 0.02·0.5 − 0.12 = 0.52`.

**Отмена:** возврат `OP_CANCEL_REFUND` (50 %) цены, агенты свободны, без последствий.

### 5.3 Последствия

| Тип | Успех | Провал |

| terror | Репутация +6; очки плана +3; влияние +3; награда 150 + 30·d k$ | Репутация −8 × legal_mult; засвеченность +8 × legal_mult; каждый агент команды погибает с шансом `clamp(0.15 − 0.02·(бой − 5) − marksman 0.05, 0.03, 0.25)` |
| infiltration | Агент в статусе `embedded` у цели. У соперника: каждый месяц `roll(EMBED_KOMPROMAT_CHANCE)` (0.5) → компромат силы 2 на этого соперника; открывает «Подставу». В движении лидера: см. §9.5. Раз в месяц `roll(EMBED_DETECT_CHANCE)` (0.04) → агент раскрыт (возвращается в `idle`, лояльность −10, засвеченность +5, соперник +1 компромат на игрока). Отозвать можно в любой момент | Агент раскрыт: засвеченность +5 × legal_mult; с шансом 0.5 потерян (пойман), иначе возвращается с лояльностью −10; соперник-цель +1 компромат на игрока |

Общее для всех операций: XP (§4.2.3); лояльность участников (+3 за успех, −5 за провал) начисляется в конце месяца; трейт «Болтун» добавляет засвеченность +1. Событие «Случайная находка»: `roll(0.05)` при любой «Слежке» (и успешной, и проваленной) → +1 компромат силы 1 на случайного соперника.
При Репрессиях 6 потери репутации от провала равны 0.

### 5.4 Дела на карте
- **Откуда берутся задания** (решение): основной поток — случайные дела на карте. Дела-теракты появляются случайно и от карточек. Цели «Слежки» и «Внедрения» игрок выбирает сам.
- Ожидаемое число обычных дел в месяц: `cases_per_month = CASE_BASE_PER_MONTH + floor((m − 1) / 12) * CASE_GROWTH_PER_YEAR + [A2]` = 6 + 1·год. Каждый день `roll(cases_per_month / 30)`.
- Дела-теракты: каждый день `roll(TERROR_PER_MONTH / 30)` (0.5 в месяц).
- Сложность обычного дела: `pickWeighted(CASE_DIFFICULTY_WEIGHTS)` = d1 25 / d2 30 / d3 25 / d4 15 / d5 5. Теракта: d3 40 / d4 40 / d5 20 (`TERROR_DIFFICULTY_WEIGHTS`).
- Штат: `pickWeighted` по `state.caseWeight` из контента (по умолчанию 1). Если в штате лидер-профсоюз с влиянием ≥ 50, штат пропускается.
- Сила улики: сразу после броска сложности `evidenceStrength = randInt(EVIDENCE_STRENGTH_RANGE)` (1..3) для каждого дела, включая теракты и дела от карточек. Это один вызов RNG на дело. На старте допроса +1, если Слежка ≥ `EVIDENCE_SURV_BONUS_MIN_LEVEL` (4), кап `EVIDENCE_STRENGTH_MAX` (3).
- Таймер до истечения: обычное `CASE_TIMER_DAYS` 15, теракт `TERROR_TIMER_DAYS` 10, плюс `SURV_L3_CASE_TIMER_BONUS` (5) при Слежке ≥ 3.
- **Доступ по полномочиям:** полные — все дела; частичные — только обычные с d ≤ 3; нет — никаких (кроме «Перехвата дела», §6.3).
- **Истечение и провал:** дело уходит держателю штата (§6.7). Если держателя нет, уходит случайному живому сопернику. Получатель: план +`RIVAL_PLAN_PER_LOST_CASE` (0.02).
- **Конкуренция за дело:** соперники не забирают дело, уже взятое игроком. Забрать его можно только через урезание полномочий (§6.4): если штат потерян во время операции, операция всё равно доигрывается.

### 5.5 План по раскрываемости

| Параметр | Значение |
|---|---|
| Что считается | Очки плана: раскрытое дело +1, раскрытый теракт +3, детектив с верным арестом +1 сверху |
| Размер плана на квартал | `target = max(PLAN_MIN, round(max(PLAN_BASE_BY_YEAR[y - 1], PLAN_PER_AGENT * agents_total * 3) * (1 - CONTROL_PLAN_REDUCTION * control / 100) * repr2_mult * card_mult))`, где `y = ceil(Q / 4)` — год квартала, `PLAN_BASE_BY_YEAR` = [6, 9, 11, 13, 15] — минимум, который правительство требует от ведомства любого размера, `PLAN_PER_AGENT` = 0.27 очка на агента в месяц, `PLAN_MIN` = 4, `repr2_mult` = 0.95 при Репрессиях ≥ 2, `card_mult` = 1.2 при карточке «Президент требует результатов». Первый квартал: `PLAN_FIRST_QUARTER` = 4. Цель фиксируется в начале квартала по составу на этот момент |
| `plan_ratio` | `(points + fake_points) / target` |
| Перевыполнение (`ratio ≥ 1.0`) | Репутация +`PLAN_OVER_REP` (3); влияние +`PLAN_OVER_INFL` (2), при `ratio ≥ 1.3` +4; больше доля бюджета через вес (§6.2) |
| Невыполнение | `ratio < PLAN_FAIL_RATIO` (0.7): репутация −5 и слушания (§9.6). `ratio < PLAN_CRITICAL_RATIO` (0.5) три квартала подряд → поражение `dismissed`; первые `DISMISS_GRACE_QUARTERS` (1) квартал в счётчик не идёт (§8.6). После второго подряд — предупреждение с автопаузой |
| «Рисовать» статистику | Да (грязное действие). До закрытия квартала можно добавить `fake_points ≤ floor(FAKE_MAX_SHARE * target)` (30 %). Каждое фальшивое очко даёт засвеченность +1. В конце квартала, если `fake_points > 0`: `F += fake_points` (накопительно за партию), `roll(clamp(FAKE_CATCH_K * F^2, 0, FAKE_CATCH_MAX))` (0.005·F², максимум 0.8; F=5 → 0.125, F=10 → 0.5). Пойман: репутация −15, засвеченность +15, «Под следствием» +15, `ratio` квартала пересчитывается без фальшивок |
| Сорвать план конкуренту | Да: «Перехват дела», «Подстава», «Лоббирование» (§6.3) |

`agents_total` — весь состав, включая агентов за рубежом, внедрённых, на обучении и на протестах. Поэтому расширение штата поднимает план, а все отвлечённые от дел агенты уменьшают реальную раскрываемость.

### 6.2 Распределение бюджета
Общий пул: `pool_monthly(q) = round(POOL_START_MONTHLY * (1 + POOL_GROWTH_PER_QUARTER)^q)` (3200 k$ × 1.02^q).
В конце квартала для каждого живого ведомства `i` (включая игрока):
```
weight_i = (0.5 + clamp(plan_eff_i, 0, PLAN_RATIO_CAP))        // CAP 1.5
// plan_eff_i = (plan_ratio_i(q) + plan_ratio_i(q-1)) / 2 — среднее за PLAN_RATIO_SMOOTHING_QUARTERS (2) квартала;
// для первого распределения plan_ratio(q-1) = 1.0
         * (0.5 + reputation_i / 100)
         * (0.5 + influence_i / 100)
         * lobbyMult_i * hearingMult_i * priorityMult_i * favor_i    // по умолчанию 1
share_i  = SHARE_FLOOR + (1 - N_alive * SHARE_FLOOR) * weight_i / Σ weight      // FLOOR 0.05
```
- Доход в конце месяца m: `income = round(pool_monthly(q(m)) * share_player * cardMult * freezeMult)`, где `share_player` взята из последнего распределения (для месяцев 1–3 — начальная доля), `cardMult` — произведение активных карточек, `freezeMult = INVESTIGATION_FREEZE_MULT` (0.8) при «Под следствием» ≥ 50, иначе 1.
- Сглаживание действует только на вес бюджета. Награды и штрафы плана (§5.5), слушания, «Чистые руки» и `dismissed` смотрят на `plan_ratio` текущего квартала.
- Начальная доля считается той же формулой с `plan_ratio = 1` для всех: доля игрока = 0.2233, доход месяца 1 = **715 k$**.
- `lobbyMult` (от лоббирования игрока) и `hearingMult` (слушания: 0.9, при Юр ≥ 3 — 0.95) действуют один квартал, потом сбрасываются в 1. `lobbyMult` минимум 0.5.
- **Изъятие остатка** («что не потратил — вернут»): сразу после распределения `cap = CARRYOVER_CAP_MONTHS * pool_monthly(q_next) * share_new` (4 месячных дохода); если `budget > cap`, изымается `round(CLAWBACK_RATE * (budget − cap))` (0.5).
- Соперники деньгами не управляют: их «бюджет» равен доле, которая влияет на силу ИИ (§6.4).
- План соперника за квартал: `planRatio = clamp(RIVAL_PLAN_MEAN + randFloat(-RIVAL_PLAN_SPREAD, RIVAL_PLAN_SPREAD) + planBonusThisQuarter, 0, 1.5)` (разброс 0.15, у SS 0.05). `planBonusThisQuarter` копит эффекты: работа +0.05, подстава −0.15, перехват −0.03, ушедшие дела +0.02. Обнуляется в конце квартала.

| Вернуть полномочия в штате | 50 k$ + 10 влияния | Штат с уровнем < 2 | Успех `clamp(0.4 + 0.004·infl + 0.05·громкие_успехи_в_штате_180д, 0.1, 0.9)` → +1 уровень | — | Нет |

Грязные действия: слив, подстава, встречный компромат, козёл отпущения, «рисование» статистики, слежка за сенатором/президентом/лидером/соперником, внедрение в соперника, шантаж, провокатор, дискредитация, задержание (квесты §9.5), любой уровень репрессий, слежка ≥ 3. Счётчик `dirtyActions` растёт на 1 за каждое такое действие, и каждое добавляет «Под следствием» +`DIRTY_INVESTIGATION_PER_ACTION` (1) × legal_inv_mult: следы остаются, даже если всё прошло гладко. Уровни репрессий и слежки считаются одним действием в момент включения. Цены грязных действий ×0.7, а их засвеченность ×0.75 при C1.
«Обида» (`grudgeUntilDay`) повышает враждебность цели (§6.4).
Громкий успех — теракт или дело с d ≥ 4. Три громких успеха в одном штате за 180 дней автоматически дают +1 уровень полномочий (максимум 2).

### 6.4 ИИ соперников (уровень правил)
Каждый живой соперник действует, когда `day >= nextActionDay`; затем `nextActionDay += interval`, где `interval = AI_ACTION_INTERVAL_DAYS` (10; police 8), при коалиции ×0.7 (`ceil`).

**Враждебность к игроку:**
```
H = clamp(AI_HOSTILITY_BASE + AI_HOSTILITY_SHARE_COEF * (share_player - 1/N_alive)     // 0.5 + 2.0*(...)

          + AI_HOSTILITY_COALITION * [coalition]                                        // +1.0
          + 0.5 * [rival == cia && max network level >= 3],
          AI_HOSTILITY_MIN, AI_HOSTILITY_MAX)                                           // 0.2 .. 2.5
```
**Выбор действия:** `pickWeighted` по `AI_WEIGHTS[style][action]`. Веса действий против игрока умножаются на `H`. Недопустимые действия получают вес 0.

### 6.6 Расформирование, поглощение, коалиция, союзы
- **Расформирование:** игрок — при `share < DISBAND_SHARE` (0.12) в двух распределениях подряд (поражение `disbanded`); ИИ — при `share < RIVAL_DISBAND_SHARE` (0.15) в двух распределениях подряд. Репутация игрока ≤ 0 — немедленное поражение `reputation`.
- **ИИ «на грани»:** когда репутация ИИ в момент изменения достигает ≤ 0, он получает статус `collapsing`: репутация замирает на 0 (дрейф и приросты не действуют), он не совершает действий и не участвует в распределении (не входит в `N_alive` и в Σ weight). Расформировывается он в конце текущего квартала, до распределения. Если в этот момент идёт поглощение, расформирование ждёт его результата: успех — поглощён, провал — расформирован сразу.
- **Штаты выбывшего ИИ.** Расформирован: где у игрока уровень ≥ 1, уровень становится 2; где 0 — остаётся 0. Поглощён: +1 уровень во всех его штатах (0 → 1, 1 → 2). Держатель в обоих случаях снимается (`holder = null`). Компромат выбывшего ИИ на игрока исчезает.
- **Поглощение:** §6.3.
- **Коалиция:** как только один ИИ выбыл или доля игрока ≥ `COALITION_SHARE` (0.40), все оставшиеся ИИ навсегда входят в коалицию: враждебность +1.0, интервал ×0.7.
- **Союзы:** формальных союзов с игроком нет. Есть только «услуга» из квеста «Сенатор» (враждебность −0.3 на 180 дней).

### 6.7 Карта полномочий
50 штатов. `stateJurisdiction[stateId] = { level: 0|1|2, holder: RivalId | null }`.
Старт ФБР: полные (2) в 10 самых населённых штатах — CA, TX, FL, NY, PA, IL, OH, GA, NC, MI (`START_FULL_STATES`), частичные (1) в остальных 40. Отсюда JP = 60.
Полномочия влияют на: доступ к делам (§5.4), лимит агентов (§4.2.1), получателя ушедших дел (держатель).
Директора посадили (`arrested`) — партия окончена сразу, смены директора нет.

## 8. Пути к победе и поражения

Все условия проверяются в конце дня (§3.3, шаг 8). Если в один день выполнено несколько, засчитывается первая по приоритету: monopoly → cardinal → shadow → 1984 → clean.

### 8.1 «1984» (`'1984'`)
- **Условие:** Репрессии 7 активны, Слежка 6 и `control >= 100` непрерывно `VICTORY_1984_HOLD_DAYS` (360) дней. Счётчик сбрасывается, если условие хоть раз нарушено.
- **Ключевые ветки:** Слежка 6, Репрессии 1–7, технология A3 (а значит, Кибер 5).
- **Ожидаемый месяц** (замер r2-final): Слежка 6 к ~M36, Репрессии 7 к ~M44, победа p10/50/90 = **49/54/59**; 40 % у целевого бота.
- **Цена:** ~8.2 тыс. k$ вложений (Кибер 5 = 2020, Слежка 1–6 = 2000, Репрессии 1–7 = 2240, ветка A = 1900) при содержании до 230 k$/мес; засвеченность +7–11/мес (скандалы почти каждый квартал, репутация и доля бюджета падают); недовольство ~70–85 до включения 7-го уровня — бунты и шанс переворота (`riot`); сети за рубежом проваливаются чаще.

### 8.2 «Тень над регионом» (`'shadow'`)
- **Условие:** во всех странах списка (`SHADOW_COUNTRIES` для ФБР: Канада, Мексика, Куба) сеть ≥ `SHADOW_NETWORK_LEVEL` (4) непрерывно `SHADOW_HOLD_DAYS` (180) дней.
- **Ключевые ветки:** B1–B3, Контрразведка, агенты с навыком слежки.
- **Ожидаемый месяц** (замер r2-final): B3 к ~M33, сети уровня 4 к M35–38, победа p10/50/90 = **37/47/57**; 40 % у целевого бота.
- **Цена:** 1900 k$ на ветку B; 6+ агентов годами вне раскрываемости, хотя они входят в цель плана (план проседает → доля бюджета); провалы сетей (засвеченность +8, репутация −5); ЦРУ враждебнее.

### 8.3 «Монополия» (`'monopoly'`)
- **Условие:** все 3 ИИ-соперника расформированы или поглощены. Доля игрока тогда автоматически равна 100 %.
- **Ключевые ветки:** слежка за соперниками (компромат), сливы, подставы, лоббирование, поглощение. Дерево не нужно.
- **Ожидаемый месяц** (замер r2-final): коалиция к ~M11 в 87 % партий, победа p10/50/90 = **26/39/53**; 48 % у целевого бота.
- **Цена:** грязные действия (засвеченность, скандалы, «Под следствием» после раскрытий); коалиция атакует в ~2 раза чаще; влияние уходит на лоббирование и поглощения.

### 8.4 «Чистые руки» (`'clean'`)
- **Условие** (проверяется только в конце месяца 60, раньше остальных проверок тайм-аута):
  1. `plan_ratio` без фальшивок ≥ 1.0 минимум в `CLEAN_MIN_QUARTERS_MET` (19) из 20 кварталов (допускается один промах);
  2. `reputation >= CLEAN_MIN_REPUTATION` (90);
  3. `exposure < CLEAN_MAX_EXPOSURE` (10);
  4. `dirtyActions == 0`, максимум репрессий за партию = 0, максимум слежки за партию ≤ `CLEAN_MAX_SURV_LEVEL` (2), `fake_points_total == 0`.
- **Ключевые ветки:** Аналитика, Оперативный, Пиар, Юротдел, Контрразведка.
- **Ожидаемый месяц:** **60** (по определению).
- **Цена:** нет компромата и подстав, от атак ИИ остаётся только пассивная защита (КР, Юр, Пиар); рост медленнее; один невыполненный квартал убивает путь. Исключает «1984», «Серого кардинала», «Монополию» (без грязных методов ИИ не выбить) и почти исключает «Тень» (провалы сетей поднимают засвеченность, а агенты вне плана).

### 8.5 «Серый кардинал» (`'cardinal'`)
- **Условие:** одновременно действующий компромат на президента и минимум на `CARDINAL_SENATORS_REQUIRED` (5) из `BUDGET_COMMITTEE_SIZE` (9) сенаторов бюджетного комитета **непрерывно** `CARDINAL_HOLD_DAYS` (120) дней. Счётчик сбрасывается, если в какой-то день условие нарушено (истёк или сгорел предмет, выборы).
- **Ответный удар во время удержания:** в конце каждого месяца, пока счётчик > 0: «Под следствием» +`CARDINAL_HOLD_INVESTIGATION` (6) × legal_inv_mult; `roll(CARDINAL_HOLD_BURN_CHANCE)` (0.15) — один случайный из засчитанных предметов на сенаторов теряет силу (сенатор опередил и сам покаялся в СМИ).
- **Ключевые ветки:** Слежка 6 (Кибер 5, технология A2), C1–C3. C3 требует Слежку 6; цель «президент» доступна при C3 и текущей Слежке 6.
- **Ожидаемый месяц** (замер r2-final): C3 к ~M42, победа p10/50/90 = **41/50/58**; 49–56 % у целевого бота. Выборы на 47-м месяце влияют: после M47 побеждают 35 % при новой администрации и 43 % при переизбрании.
- **Цена:** «Слежка» за сенатором/президентом (d3–5/d5, засвеченность +12 за попытку, `ILLEGAL_TARGET_EXPOSURE`); провал «Слежки» за президентом добавляет «Под следствием» +20 и запускает слушания; компромат истекает за 360 дней (без C2 для сенаторов); выборы могут обнулить компромат на президента.

### 8.6 Поражения

| Код | Условие |
|---|---|
| `bankrupt` | `budget < 0` в конце месяца `BANKRUPT_MONTHS` (3) месяца подряд; месяцы 1–`BANKRUPT_GRACE_MONTHS` (9) в счётчик не идут, поэтому самое раннее банкротство — M12. Без грейса и в любой месяц: `budget < −BANKRUPT_HARD_FLOOR_MONTHS × max(lastIncome, firstIncome)` (6) в конце месяца → банкротство сразу. `firstIncome` — доход месяца 1 (§6.2; при стандартных константах 715, жёсткий порог −4290); он фиксируется на старте партии и хранится в сейве, поэтому порог не сжимается вместе с падающим доходом |
| `reputation` | `reputation <= 0` |
| `arrested` | `investigation >= 100` |
| `riot` | Успешный бросок переворота (§4.4.4) |
| `dismissed` | `plan_ratio < 0.5` три квартала подряд; первые `DISMISS_GRACE_QUARTERS` (1) квартал в счётчик не идёт (штраф −5 репутации и слушания за план < 0.7 действуют), самое раннее — M12 |
| `disbanded` | Доля игрока < 0.12 в двух распределениях подряд; первые `DISBAND_GRACE_QUARTERS` (2) распределения (M3, M6) не учитываются, самое раннее — M12 |
| `timeout` | Конец месяца 60, победы нет («Чистые руки» проверяются перед этим) |

**Защита первого года.** Бездействующий игрок не проигрывает раньше M12: у `bankrupt`, `disbanded` и `dismissed` есть грейс. Раньше возможны только мгновенные поражения-катастрофы. Игрок, который нанимает и тратит сверх дохода, может дойти до первой из них. По замеру r3-final, при пороге 6 месячных доходов раньше M12 умирают 5.5 % случайных ботов (при пороге 3 было 27 %); целевые боты до порога не доходят:
- долг больше 6 месячных доходов (`BANKRUPT_HARD_FLOOR_MONTHS`, от `max(lastIncome, firstIncome)`) — при найме и тратах сверх дохода;
- `reputation` — репутация 0 (со старта 50, а дрейф тянет к 50: нужны серия провалов, скандалов или пойманные фальшивки);
- `arrested` — «Под следствием» 100 (начинается с 0: только раскрытые подставы, пойманные фальшивки, скандалы при засвеченности ≥ 50 и компромат у соперников);
- `riot` — переворот при недовольстве ≥ 80 (со старта 15: только быстрое включение нескольких уровней репрессий).
Грейса у этих поражений нет намеренно: это наказание за выбранный риск, а не за неопытность.

### 8.7 Счёт (таблица рекордов)
```
score = max(0, round(
    [victory] * (SCORE_VICTORY + SCORE_PER_MONTH_LEFT * (60 - months_played))   // 10000, 100
  + SCORE_PER_REPUTATION * reputation       // 20
  + SCORE_PER_INFLUENCE  * influence        // 10
  + budget / SCORE_BUDGET_DIVISOR           // 10
  - SCORE_PER_EXPOSURE   * exposure         // 10
))
```

### 9.1 Заброска шпиона и сети за рубежом
Требует B1. Выбор: агент, страна из `SHADOW_COUNTRIES`, цель (министерство / армия / СМИ / оборонный завод — влияет только на текст), легенда.

| Легенда | Провал на границе `LEGEND_BORDER_FAIL` | Внедрение, бонус | Прогресс сети ×`LEGEND_NET_GROWTH` | Цена, k$ |
|---|---|---|---|---|
| Дипломат | 0.05 | 0 | 0.8 | 80 |
| Бизнесмен | 0.10 | +0.05 | 1.0 | 60 |
| Журналист | 0.15 | +0.05 | 1.2 | 40 |
| Студент | 0.20 | +0.10 | 0.7 | 20 |

1. **Подготовка:** `ZABROSKA_PREP_DAYS` (20) дней, агент занят; +`ZABROSKA_PREP_BONUS` (0.10) к внедрению. Можно пропустить.
2. **Заброска:** провал = `roll(clamp(LEGEND_BORDER_FAIL − 0.03·[язык] − 0.05·[cold_blooded], BORDER_FAIL_MIN, BORDER_FAIL_MAX))` (0.01..1) → агент пойман (потерян). Отдельно `roll(0.10)` — «Агента узнали в аэропорту»: выбор «бежать» (агент вернулся, квест провален) или «импровизировать» (бросок провала на границе ещё раз ×2).
3. **Внедрение:** `ZABROSKA_INFILTRATE_DAYS` (30) дней; `p = clamp(ZABROSKA_INFILTRATE_BASE + ZABROSKA_SKILL_COEF·(слежка − ZABROSKA_SKILL_PIVOT) + бонусы, ZABROSKA_CHANCE_MIN, ZABROSKA_CHANCE_MAX)` (0.5 + 0.04·(слежка − 5), кламп 0.05..0.95). Бонусы: подготовка 0.10, легенда (`LEGEND_INFILTRATE_BONUS`), курс легенды 0.05, `cold_blooded` 0.05. Провал: агент возвращается, засвеченность +3.
4. **Вербовка источника:** деньги (60 k$, p 0.7), идеология (0 k$, p 0.4), компромат (1 предмет любой, p 0.85, но этот источник удваивает шанс «двойного агента»). Неудача: через `RECRUIT_RETRY_DAYS` (30) дней — новый выбор способа (шаг квеста с автопаузой), варианты без нужного ресурса неактивны. Если повтор идёт без выбора (бот, автосимуляция), берётся прежний способ, а если он недоступен — первый доступный из `RECRUIT_FALLBACK_ORDER` (деньги → идеология). Успех: если сеть страны = 0, она становится 1.
5. **Работа:** агент в статусе `abroad`. Ежемесячно на страну:
   ```
   progress += Σ_agents NET_PROGRESS_PER_AGENT * (1 + 0.05*(слежка - 5)) * LEGEND_NET_GROWTH * lang(1.1) * [B2 ? 1.25 : 1]   // 0.28
   while progress >= NET_PROGRESS_TO_NEXT * (level + 1) && level < cap:  progress -= NET_PROGRESS_TO_NEXT * (level + 1); level += 1   // 0.5
   ```
   cap: 0 без B, 2 при B1, 3 при B2, 5 при B3. Добыча: `roll(NET_KOMPROMAT_PER_LEVEL * level)` (0.04·ур) → 1 компромат силы 2 (70 % на соперника, 30 % на случайного сенатора).
6. **Провал сети** (ежемесячно, при уровне ≥ 1): `p = clamp(NET_FAIL_PER_LEVEL·level + COUNTRY_CI[c] + 0.005·repr_level − 0.004·КР + 0.05·[дипкризис], 0.005, 0.2)`, где `NET_FAIL_PER_LEVEL` = 0.005, `COUNTRY_CI` = Канада 0.01, Мексика 0.015, Куба 0.03. Провал: сеть −1 (`NET_FAIL_EFFECT.levels`), случайный агент страны пойман и дополнительно снимает `CAPTURE_NET_LEVEL_LOSS[band]` уровней (см. ниже), репутация −5, засвеченность +8 (у Канады как союзника ×1.5).
   **Поимка агента за рубежом** (любая: провал сети, проверка при эвакуации): сеть страны −`CAPTURE_NET_LEVEL_LOSS[band]`, где `band` — полоса лояльности по `LOYALTY_BANDS`: 0–19 → 5 (сеть → 0), 20–39 → 1, 40–69 → 0, 70–100 → 0. Уровень не опускается ниже 0.
   **Двойной агент раскрыт:** `roll(0.03)` в месяц при уровне ≥ 2 → цепочка «Чистка в сети»: «чистить» (50 k$, 20 дней без прогресса) или «игнорировать» (ЦРУ +1 компромат на игрока каждый месяц, пока не почищено).
   **Отзыв:** агент возвращается через 10 дней, сеть −1. **Обмен пленными** (квест): за пойманного агента — 100 k$ и влияние −5, агент возвращается с лояльностью +10.

### 9.2 Поимка преступника (детектив)
Опционально для дел d ≥ 4: вместо автоброска игрок может вести детектив. ИИ и симулятор всегда используют автобросок.
- Подозреваемых: `DETECTIVE_SUSPECTS` (5), −1 при Аналитике ≥ 3. Лимит `DETECTIVE_TIME_LIMIT_DAYS` (30) дней с начала операции.
- Каждое действие занимает 3 дня: «Слежка за подозреваемым» (p = 0.6 + 0.04·(слежка − 5), −1 подозреваемый); «Опрос свидетелей» (p 0.7, −1; событие «Свидетель передумал» `roll(0.15)` → +1 подозреваемый обратно); «Запрос данных» (Слежка ≥ 2: −1 автоматически; ≥ 4: −2; 1 раз за дело).
- «Арест»: успех с шансом `1 / оставшихся`. Верный арест = успех операции +1 очко плана. Неверный: репутация −5 и дело уходит сопернику.
- Время вышло: преступник бежит, операция провалена, в другом штате появляется дело `d = min(5, d + 1)`.

### 9.3 Допросы
Опционально после успешного «Расследования» d ≥ 3. Даёт +1 очко плана при признании. Шкалы подозреваемого: Стресс S (старт 20), Ложь L (старт `randInt(60, 90)`). Признание при `L <= 20`. «Сломался сам» — при `S >= 90` признание мгновенное. Максимум `INTERROGATION_MAX_ROUNDS` (6) раундов.

| Хороший/плохой коп | S +20, L −10 | Нужны 2 агента в команде |
| Сделка | Признание сразу, но очко плана за допрос 0; создаётся связанное дело d − 1 («подельник») | — |

### 9.5 Диалоговые квесты (числа)
Длительность «N дней» во всех квестах — `QUEST_ACTION_DAYS` (30), если не указано иное.

**Лидеры** (квест закреплён за архетипом: профсоюзный лидер → «Встреча с профсоюзом», блогер → «Блогер с документами», правозащитник → «Митинг у здания», бывший агент → «Перебежчик выходит на связь»; та же сцена «Перебежчик» запускается и по `DEFECTOR_RETURN_CHANCE`, §4.2.7):
- «Встреча с профсоюзом»: Уступить → откат репрессий на 1 уровень, влияние лидера −30, недовольство −10. Внедрить агента → 30 дней, `roll(0.6)`: лидер «под колпаком» (его влияние растёт вдвое медленнее, его квесты дают +1 вариант «знаем заранее»), иначе агент раскрыт (засвеченность +`QUEST_UNION.infiltrateFailExposure` = 5). Отказать → влияние лидера +15, забастовка в штате (дела не появляются 60 дней).
- «Блогер с документами»: Дискредитировать (1 компромат любой) → `roll(0.7)`: влияние −40, иначе влияние +30 и засвеченность +5. Сделка → 100 k$, молчит; `roll(0.3)` вернётся через `randInt(90, 180)` дней. Задержать (Репр. 5) → влияние +30, `roll(0.5)` протест по стране (недовольство +10).
- «Митинг у здания»: Разогнать → контроль-бонус +5, недовольство +15, засвеченность +5. Дать пройти → влияние −5, недовольство −5. Провокатор → `roll(0.5)`: влияние лидера −25; иначе скандал (репутация −5, засвеченность +10).
- «Перебежчик выходит на связь»: Вернуть → агент возвращается с лояльностью 20. Суд по старому делу (Юр 3) → влияние лидера-перебежчика −50 (или угроза снята). Игнорировать → сеть в случайной стране −1.

**Прочие:**
- «Информатор в мэрии» (каждый месяц `roll(0.05)`, откат 360 дней): Заплатить 60 k$ → `roll(0.7)`: +1 дело без таймера в месяц на 6 мес; иначе двойной агент (случайный ИИ +2 компромат). Через компромат → 1 предмет, +1 дело без таймера в месяц на 4 мес, **без** броска честности (под давлением он не работает на конкурента, но и служит недолго). Сдать полиции → репутация +3, план полиции +0.05.
- «Сенатор с секретом» (каждый месяц `roll(0.10)` при Слежке ≥ 3, откат 180 дней; ещё компромат на сенатора может прийти от сети, §9.1, тогда квест открывается сразу): игрок получает компромат силы 1 на случайного сенатора. Шантажировать → влияние +(5 + 3·сила), `roll(0.25)`: скандал (репутация −5, засвеченность +10, «Под следствием» +5); компромат не расходуется, откат по сенатору 180 дней. Придержать → лежит до истечения. Слить конкуренту → его влияние +10, «услуга»: его враждебность −0.3 на 180 дней.
- «Агент просит эвакуации» (`roll(0.05)` в месяц на агента за рубежом): угроза реальна с шансом 0.4 (решается при старте). Эвакуировать → 150 k$, сеть −1. Оставить → если реальна, `roll(0.4)`: сеть страны → 0 и агент потерян. Проверить → 20 дней; если реальна, `roll(0.2)` агент пойман; правда раскрыта, выбор повторяется без опции «проверить».
- «Журналист копает» (`roll(clamp((exposure − 30) / 200, 0, 0.3))` в месяц): Подкупить 80 k$ → `roll(0.6)`, иначе статья. Дискредитировать (1 компромат) → `roll(0.75)`, засвеченность +5; провал = статья. Задержать (Репр. 5) → недовольство +5, статья за рубежом (репутация −3). Игнорировать → `roll(0.5)` статья. Статья: репутация −8, засвеченность +5.

### 9.6 Слушания в Конгрессе

Выводы и как это читать:
- **Месяц 1:** +324/мес при стартовом бюджете 1500. Первый год уходит на найм (≈ 600) и отделы (≈ 1300), к концу года свободных денег ≈ 1–2 тыс. Копить бесконечно не получится: остаток сверх 4 месячных доходов наполовину изымается при распределении.
- **Месяц 24:** +75. Рост упирается в доход: каждый следующий опытный агент (≈ 55/мес) съедает почти весь профицит. Остатка хватает на 1 уровень отдела в квартал.
- **Месяц 48:** +38 при составе 16. Это потолок честного игрока: 17-й ветеран (≈ 100/мес) уводит баланс в минус. Банкротится только тот, кто нанимает сверх дохода или проваливает план.
- **Грязный, м24:** профицит меньше (+22), состав меньше, доля выше на 0.03, хотя годовой пол плана (9) не даёт маленькому штату выполнять план без фальшивок; и есть активы (компромат, внедрённые агенты), которые дальше режут долю соперников. Цена — засвеченность ~30–45, то есть 3–12 % скандала в месяц, и рост «Под следствием». Выше среднее, выше дисперсия.
- Петли обратной связи: план → вес → доход → агенты → цель плана (растёт с составом, §5.5). Состав и бюджет стабилизируются сами, если игрок не перегибает.

## 11. Платформа и технологии

### 11.1 Стек (без изменений относительно исходника)
SvelteKit + Svelte 5 + TypeScript; Vercel (`@sveltejs/adapter-vercel`); libSQL: локально файл `local.db`, в проде Turso; Drizzle ORM + drizzle-kit; свой тикер на `requestAnimationFrame` (тонкий адаптер над чистым ядром); seeded RNG; карта — SVG + d3-geo + us-atlas; квесты — Ink (inkjs); Tailwind; анимации — transitions Svelte; автосейв в IndexedDB и синхронизация в базу; игроки — анонимный id в cookie, позже авторизация; тесты — Vitest и Playwright.
Архитектура: вся игра в браузере, сервер только хранит партии.

### 11.2 База данных
Таблицы `players`, `runs`, `saves`, `results` — как в исходнике. Уточнения:
- `runs.agency`: `'fbi'` (в v1 единственное значение).
- `saves`: `run_id` (PK, FK → runs), `game_month` INTEGER 0..60, `state_json` TEXT (весь `GameState`, включая `schemaVersion` и состояние RNG), `updated_at`.
- `results.victory_path`: `'1984' | 'shadow' | 'monopoly' | 'clean' | 'cardinal' | NULL`.
- `results.defeat_reason`: `'timeout' | 'arrested' | 'bankrupt' | 'riot' | 'reputation' | 'dismissed' | 'disbanded' | NULL`.
- `results.score` — формула §8.7.

### 11.3 Что хранится в сохранении (`GameState`)
Для scaffolder: в БД это один JSON-blob, отдельные таблицы не нужны. Состав:
- `schemaVersion`, `seed`, `rngState`, `day`, `speed`, `paused`, `autopause` (флаги).
- Экономика: `firstIncome`, `lastIncome`.
- Ресурсы: `budget`, `reputation`, `influence`, `exposure`, `investigation`, `control`, `controlBonus`, `unrest`.
- `departments` (6 уровней) и стройки `{ dept, targetLevel, doneDay }[]`; `survLevel`, `survMaxEver`; `reprLevel`, `reprMaxEver`, `reprRollbacks[]` (для «Оттепели»).
- `research` `{ techId, doneDay } | null`, `techs[]`, `apexChosen`.
- `agents[]` (§4.2.1), `hirePool[]`, `defectors[]`.
- `cases[]` `{ id, kind, stateId, difficulty, expiresDay, evidenceStrength, rewardMult }`.
- `operations[]` `{ id, type, caseId|target, agentIds, extraJoinedLate[], startDay, endDay, cost }`.
- `kompromat[]` (§2.5).
- `rivals[]` (§6.1), `coalition`.
- `stateJurisdiction` (50 записей).
- `networks` `{ countryId: { level, progress, agentIds, doubleAgentActive } }`.
- `leaders[]` `{ id, archetype, stateId, influence, flags }`.
- `senators[]` `{ id, resistance: 1..3 }` (§5.1), `presidentTerm` (номер администрации).
- `plan` `{ quarter, target, points, fakePoints, fakeTotal, ratioHistory[], criticalStreak, metCount }`.
- `cards` `{ nextCardDay, cooldowns, active: { id, untilDay, params }[] }`.
- `quests` — активные Ink-сессии (`inkStateJson`, `questId`, этап, таймер).
- `counters` `{ dirtyActions, counterKompromatReadyDay, holdCardinalDays, bankruptStreak, lowShareStreak, hold1984Days, holdShadowDays, lastHearingDay, sabotageCountByRival }`.
- `log[]` — журнал событий (последние 200 записей, старые отбрасываются).
- `outcome` `{ status: 'active'|'won'|'lost', victoryPath, defeatReason, month }`.
